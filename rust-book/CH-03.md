### Invalid Array Element Access

- Arrays are zero-indexed: `[1, 2, 3, 4, 5]` has valid indices `0`–`4`.
- Code using a user-provided index can compile successfully. Rust checks bounds at runtime because the input is unknown at compile time.
- If `index >= a.len()`, `a[index]` panics (e.g., `index out of bounds: the len is 5 but the index is 10`). Execution stops before the final `println!`.
- Bounds checking prevents invalid memory access, enforcing Rust’s memory safety.
