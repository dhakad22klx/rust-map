### Invalid Array Element Access

- Arrays are zero-indexed: `[1, 2, 3, 4, 5]` has valid indices `0`–`4`.
- Code using a user-provided index can compile successfully. Rust checks bounds at runtime because the input is unknown at compile time.
- If `index >= a.len()`, `a[index]` panics (e.g., `index out of bounds: the len is 5 but the index is 10`). Execution stops before the final `println!`.
- Bounds checking prevents invalid memory access, enforcing Rust’s memory safety.

### Statements and Expressions

- **Statements** perform actions without returning a value, e.g., `let x = 5;`.
- **Expressions** evaluate to a value, e.g., `5 + 1`. Function calls and blocks are also expressions.
- A block’s final expression becomes its value. Adding `;` discards that value, so the block evaluates to `()` (the unit value).

```rust
let y = {
    let x = 3; // Statement
    x + 1      // Expression without a semicolon
}; // y is 4
```

### Control Flow

Source: [Control Flow — The Rust Programming Language](https://doc.rust-lang.org/book/ch03-05-control-flow.html).

#### `if` Expressions

- Use `if`, `else if`, and optional `else`. Conditions require `bool`; other types aren't implicitly converted.
- The first matching branch runs; later conditions are skipped.
- `if` can initialize variables. Branch values need matching types; omit trailing semicolons to produce values.

```rust
let number = if true { 5 } else { 6 }; // number is 5
```

#### Loops

- `loop` repeats until stopped. `break` exits; `continue` skips the remaining iteration.
- `loop` can produce a value with `break value;`:

```rust
let mut count = 0;
let total = loop {
    count += 1;
    if count == 3 {
        break count * 2;
    }
}; // total is 6
```

- `break` and `continue` target the innermost loop. Label an outer loop `'outer: loop { ... }` to use `break 'outer;` or `continue 'outer;`.
- `return` exits the entire function.
- `while` checks a Boolean condition before each iteration; its body may never run.
- `for` iterates over collections or ranges, avoiding manual indexing mistakes. `1..4` excludes `4`; `.rev()` reverses iteration:

```rust
for number in (1..4).rev() {
    println!("{number}"); // Prints 3, then 2, then 1
}
```
